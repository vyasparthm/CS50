| Method | Description | Example |
| :--- | :--- | :--- |
| **append()** | Adds an element to the end of the list | `list.append(x)` |
| **extend()** | Adds all elements of an iterable to the end | `list.extend(iterable)` |
| **insert()** | Inserts an item at a defined index | `list.insert(i, x)` |
| **remove()** | Removes the first item with the specified value | `list.remove(x)` |
| **pop()** | Removes and returns the element at the given position | `list.pop([i])` |
| **clear()** | Removes all items from the list | `list.clear()` |
| **index()** | Returns the index of the first element with the specified value | `list.index(x)` |
| **count()** | Returns the number of elements with the specified value | `list.count(x)` |
| **sort()** | Sorts the list in ascending order (in-place) | `list.sort()` |
| **reverse()** | Reverses the order of the list (in-place) | `list.reverse()` |
| **copy()** | Returns a shallow copy of the list | `list.copy()` |
